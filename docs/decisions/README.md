# Decision log

Record durable product and engineering decisions here as short Architecture Decision Records (ADRs). This prevents settled reasoning from being lost or repeatedly debated.

## Format

Each decision should include:

- Status: proposed, accepted, superseded, or rejected
- Date
- Context
- Decision
- Consequences
- Alternatives considered
